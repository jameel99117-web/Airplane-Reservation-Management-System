## 🚀 Features

* ✈️ Flight search and reservation
* 👤 Passenger management
* 👨‍💼 Agent dashboard
* 📊 Manager analytics
* 🛡️ Admin dashboard
* ⭐ Passenger loyalty management
* 🔐 Role-based access
* 📱 Responsive UI
* 📈 Dashboard-based operations

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Deployment:** Vercel
* **Tools:** Git & GitHub

## ⚙️ Run Locally

```bash
git clone YOUR_REPOSITORY_URL
cd Airline-Reservation-Management-System
npm install
npm start
```

For development:

```bash
npm run dev
```

| Role         | Function                                |
| ------------ | --------------------------------------- |
